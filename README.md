İTÜ Rover Engel Kaçınma Ödevi

Bu proje, ROS ve Gazebo ortamında robotun LiDAR verilerini kullanarak engellerden kaçınması için hazırlanmıştır. Robot, çevresindeki açıklıkları değerlendirerek ilerleyeceği yönü ve hızını belirler.

- scripts: Engel kaçınma kodu.
- launch: Başlatma dosyaları.
- CMakeLists.txt ve package.xml: ROS paket yapılandırması.
- Rover_Arastirma.pdf: Araştırma ödevi.
- Ekran_Kaydı_Rover.mp4: Simülasyondaki çalışma videosu. İzlemek için dosyayı indirin.
